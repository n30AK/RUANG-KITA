Keputusan World Engine

Status: Phase 4 berjalan — World Simulation & Engine Interoperability. Fondasi komunitas Phase 2 tetap dipertahankan; keputusan ditinjau ulang berdasarkan bukti dan benchmark.

Keputusan

Gunakan Three.js sebagai renderer tunggal. Definisi tempat berada pada public/scenes.js; public/app.js membangun scene, avatar, kamera, dan kontrol. Aset dari tool atau engine lain dipertimbangkan melalui glTF 2.0/GLB, bukan dengan menjalankan beberapa renderer penuh secara bersamaan.

Alasan

  • Mengurangi ukuran runtime dan konflik render loop.
  • Memudahkan debugging dan menjaga fokus MVP.
  • Mempertahankan konfigurasi scene yang seragam dan dapat diperluas.

Konsekuensi dan batasan

  • Babylon.js dan Godot belum diklaim sebagai runtime terintegrasi.
  • World Guard saat ini deterministik di browser: NPC roaming, kendaraan ambient, prediksi lintasan pendek, dan audit anomali; bukan reasoning LLM.
  • Adapter glTF/GLB tersedia dengan manifest asal, lisensi, dan atribusi; aset produksi Babylon.js/Godot belum diimpor dan runtime kedua engine tidak dijalankan.
  • Belum ada physics engine penuh/CCD, navmesh, atau multiplayer server-authoritative; collision menggunakan collider sederhana.
  • CDN/WebGL tetap membutuhkan konektivitas dan dukungan browser.

Rencana validasi

Uji live v18: WebGL dan render loop aktif; self-test 10/10 lulus pada Angkringan, Cafe, dan Pantai termasuk injeksi anomali dan recovery; input keyboard menggerakkan avatar; model glTF sintetis berhasil dimuat/dilepas; jalur aset rusak terdeteksi dan pulih setelah retry; geometri GPU stabil saat enam perpindahan scene; tidak ada console error. Viewport mobile nyata, aset GLB produksi, dan multiplayer dua browser masih NOT TESTED. Keputusan engine ditinjau ulang jika benchmark menunjukkan manfaat terukur.
